# Akhil — Digital Identity

A dark Web3-inspired single-page resume built with Next.js, TypeScript, Framer Motion and Lucide.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Customize

Edit `data/profile.ts` for:
- name
- email / LinkedIn / GitHub
- stats
- skills
- career timeline
- projects

Replace the placeholder contact links before deployment.

## Deploy

Recommended: Cloudflare Pages or another Next.js-compatible host.
